## 延迟低不低，看的是回程走哪条线

日本机房里同时跑着好几条性质完全不同的线路，价格能差三四倍，原因就在这：

| 线路类型 | 大致路由 | 大陆访问体感 | 适合谁 |
| --- | --- | --- | --- |
| CN2 GIA（CTGnet） | 电信顶级国际专线，回程不进拥堵公网 | 东京通常 50–90ms，晚高峰劣化小 | 建站、API、对稳定性敏感的业务 |
| 联通 9929 / 10099 | 联通精品网，出口速率大 | 联通用户体感明显好于普通线路 | 联通宽带用户 |
| CMI | 移动国际出口，直达香港/东京 | 移动用户友好，去程直连 | 移动为主、跑流媒体 |
| 国际 BGP（NTT 等） | 纯国际路由，不做大陆优化 | 电信可能绕美，延迟 160ms+，晚高峰丢包 | 落地、面向海外用户、测试 |

参考区间：香港走优化线路大概 20–50ms，东京 50–90ms，洛杉矶即便挂 CN2 GIA 也常年在 150–200ms。东京的价值就在于——需要日本 IP 的时候，它比洛杉矶便宜一截、又比香港近一截。

## 几个常见问题

**日本一定比香港快吗？**
不一定。香港走优化线路通常 20–50ms，东京 50–90ms。东京胜出的场景是"你需要日本 IP"或者"香港机房太贵/没货"，单纯追最低延迟的话，香港仍然更近。

**T1 便宜这么多，能不能凑合用？**
看用途。面向海外用户、只做落地，T1 完全够；指望它优化大陆访问，就不合适了——电信去程经常绕美国，延迟直接翻倍。

**月付还是年付？**
第一次用建议月付。优化线路的实际表现跟你所在地区、运营商强相关，别人测出来的 60ms 不代表你能测出 60ms。跑满一个月确认晚高峰没问题，再换年付拿循环折扣。

**能解锁 Netflix、TikTok 这些吗？**
第三方实测里 DMIT 的原生 IP 解锁情况不错，但商家不做任何保证，IP 段也会变。有刚需的话，按自己的实际测试为准。

说到底，日本低延迟 VPS 这件事没有玄学：确认线路类型、拿测试 IP 自己 ping、看清超量后会怎样，三个动作做完，剩下的就是预算问题了。
